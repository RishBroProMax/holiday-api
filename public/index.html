📌 Key API Endpoints

GET
/api
Base API overview endpoint returning metadata, version, and list of available endpoint routes.
GET
/api/v1/holidays
List holidays with query filters: ?year=2026, ?month=5, ?type=buddhist, ?public=true
GET
/api/v1/holidays/upcoming
Get the next upcoming holiday from today's date in Asia/Colombo timezone. Includes countdown daysUntil.
GET
/api/v1/holidays/today
Check if today is a public holiday in Sri Lanka. Returns boolean isHoliday.
GET
/api/v1/holidays/year/:year
Get all holidays for a specific year (2024 through 2045).
GET
/api/v1/holidays/date/:date
Check if a specific date (YYYY-MM-DD) is a Sri Lankan holiday.
